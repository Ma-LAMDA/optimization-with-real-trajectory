## GNS3 环境接口

可以通过GNS3 环境接口查询设备的配置和回显。需要查询网络项目、设备列表、设备配置或命令回显时，可按下面接口文档调用 GNS3 环境接口。

**📡 GNS3 API 文档 **

服务运行在127.0.0.1服务器 `3080` 端口。

**服务概览**

- **基础 URL**: `http://127.0.0.1:3080`
- **API 版本**: v3

**接口列表**

1. **获取所有项目列表**
    - **方法**: `GET`
    - **路径**: `/v3/projects`
    - **描述**: 返回本地数据中包含的所有网络项目名称。
    - **请求参数**: 无
    - **响应 (200)**:

```
[
  {{
    "name": "net7",
    "project_id": "a1b2c3d4-e5f6-7890-g1h2-i3j4k5l6m7n8"
  }},
  ...
]
```

2. **获取指定项目的节点列表**
    - **方法**: `GET`
    - **路径**: `/v3/projects/{{project_id}}/nodes`
    - **描述**: 根据项目 ID 获取该项目下的所有设备节点。
    - **路径参数**:

|    参数名     |  类型   |     说明       |
| ------ |------ |------ |------ |
| `project_id` | String | 项目的唯一标识符 |

- **错误响应**:
        - `404 Not Found`: 项目不存在或无节点数据。
- **成功响应 (200)**:

```
[
  {{
    "name": "Spine1",
    "status": "started",
    "node_id": "Spine1"
  }},
  {{
    "name": "Leaf1",
    "status": "started",
    "node_id": "Leaf1"
  }}
]
```

3. **获取节点命令回显**
    - **方法**: `GET`
    - **路径**: `/v3/projects/{{project_id}}/nodes/{{node_id}}/command`
    - **描述**: 模拟执行 CLI 命令，返回预先存储的命令输出结果。
    - **路径参数**:

| 参数名 | 类型 | 说明 |
| `project_id` | String | 项目名称 (用于匹配 JSON 层级) |
| `node_id` | String | 节点名称 |

- **查询参数**:

| 参数名 | 类型 | 必填 | 说明 |
| ------ |------ |------ |------ |
| `cmd` | String | 是 | 要执行的命令 (如 `display ip interface brief`) |

- **成功响应 (200)**:

```
{{
  "command": "display version",
  "output": "Huawei Versatile Routing Platform Software\\nVRP (R) software, Version 8.20 ... [Output Truncated]"
}}
```

- **失败响应 (200)**:
        - 如果未找到对应命令数据，`output` 字段将返回错误提示：

```
{{
  "command": "invalid_cmd",
  "output": "Error: Command 'invalid_cmd' not found in mock data."
}}
```
