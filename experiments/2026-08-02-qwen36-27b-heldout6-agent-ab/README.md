| 指标 | Base | LoRA | LoRA - Base |

LoRA 在这组最新留出题上的严格准确率从 23.33% 提升到 40.00%，提升 16.67 个百分点；
正确次数相对增加 71.43%。提升主要来自题 12（0/5 → 5/5）和题 24（1/5 → 2/5）；
题 40、72 仍为 0/5，题 86 从 3/5 降到 2/5，题 100 保持 3/5。LoRA 的平均和中位耗时
明显下降，但超时比 Base 多 1 次，因此结论应表述为“严格准确率和典型耗时改善”，不能表述为
“所有题目或超时率均改善”。这六题来自最新留出划分，且两侧使用相同 prompt、工具、题目、
重复次数、3600 秒上限与单实例双并发拓扑，因此是当前正式的端到端泛化 A/B 结论。
