# Codex IP 轨迹实验（10 题 × 10 次）

本目录保存 2026-07-28 使用本地 Codex CLI、`gpt-5.6-sol` 和本地
`saved_configs_service` 重新生成的 IP 故障分析原始轨迹。

所有新文件均位于本目录。输入只读来源为
`data/simulation/train_0629.jsonl` 和 `data/simulation/IP user prompt.txt`；运行时仅把
原始 prompt 中的服务主机 `10.139.194.154` 替换成 `127.0.0.1`。模型只能通过
`http://127.0.0.1:3080` 查询配置，不得直接读取仓库的 `saved_configs/`。

## 运行

先确认本地服务健康，再从仓库根目录执行：

```powershell
python -B experiments/2026-07-28-ip_codex_train0629_10x10/scripts/run_codex_ip_trajectories.py
```

中断后可用同一命令恢复；运行器固定写入 `results/runs/fullaccess/`，已成功槽位不会
重复调用。额度或用量限制沿用上次实验规则：保留失败 attempt，等待 1,800 秒后重试
同一槽位；其他非额度错误停止整批任务。

完成后校验：

```powershell
python -B experiments/2026-07-28-ip_codex_train0629_10x10/scripts/validate_experiment.py
```

## Completed-run integrity

- The final manifest contains 100 successful slots and 100 unique Codex thread IDs.
- Four earlier attempts that directly named protected repository paths are retained
  as rejected policy violations; each affected slot was regenerated by a new call.
- One in-progress attempt stopped for the systemic audit is retained as interrupted;
  its slot was regenerated by a new call.
- The resumed 40 successful calls used a reviewed PreToolUse API-only hook. The
  earlier 60 successful calls were audited from their full event streams.
- results/reports/validation.json is the machine-readable final integrity report.

## Directory relocation

The experiment directory was renamed from ip_codex_0728_10x10 to
2026-07-28-ip_codex_train0629_10x10 after generation. Current operational
configuration and documentation use the new path. Absolute paths retained inside
attempt metadata, raw event streams, and runner logs are immutable historical
records of the commands that originally ran; changing them would falsify the raw
trajectory and invalidate recorded hashes. See runtime/relocation.json.

`data/simulation/train_0629.jsonl` 的 `answer` 字段作为标准答案。判分口径与
2026-07-27 的 14x10 实验一致：解析每个有效成功 attempt 的 `<result>` JSON
列表，将其作为故障集合精确比较；忽略列表顺序，但漏报、多报、错报均判错。
